# Global Healthcare Spending & Outcomes Analysis

## Project Overview

This project explores global healthcare spending patterns and evaluates how healthcare expenditure relates to health outcomes such as life expectancy, mortality rates, and healthcare access across countries.

The goal is to understand whether higher healthcare spending leads to better outcomes and to identify inefficiencies and inequalities in global healthcare systems.

---

## bjective

To analyze healthcare spending efficiency across countries and determine how financial investment in healthcare impacts overall population health outcomes.

---

## Key Questions

This project aims to answer the following questions:

* Do countries with higher healthcare spending achieve better health outcomes?
* Which countries are the most efficient in converting spending into positive health outcomes?
* Where does healthcare inequality exist globally?
* How does government spending compare to private out-of-pocket healthcare costs?
* Are there countries that outperform others despite lower healthcare expenditure?

---

## Analytical Approach

The project will follow a structured data analysis workflow:

1. Data collection from global healthcare datasets (WHO / World Bank)
2. Data cleaning and transformation using SQL Server
3. Exploratory Data Analysis (EDA) to identify patterns and trends
4. KPI development to measure healthcare efficiency
5. Data modeling and visualization in Power BI
6. Insight generation and business recommendations

---

## Tools Used

* SQL Server (Data extraction, cleaning, and analysis)
* Excel (Initial data exploration)
* Power BI (Dashboard creation and visualization)
* GitHub (Version control and project documentation)

---

## Expected Insights

This analysis is expected to reveal:

* Differences in healthcare efficiency across countries
* Relationship between healthcare spending and life expectancy
* Regions with healthcare inequality or underinvestment
* Countries achieving strong outcomes with limited resources
* Global trends in healthcare spending allocation
